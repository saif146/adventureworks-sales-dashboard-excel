# 📊 Adventure Works Sales Dashboard (Excel BI Project)

An advanced interactive Excel Dashboard project built using:

- Power Query
- Power Pivot
- DAX
- Excel Functions
- Pivot Charts
- Data Modeling
- Interactive Visual Storytelling

This project transforms raw sales data into actionable business insights through dynamic dashboards and KPI-driven analytics.

---

# 🚀 Project Overview

This dashboard analyzes Adventure Works sales data and provides deep insights into:

✅ Revenue Trends  
✅ Profitability Analysis  
✅ Customer Insights  
✅ Product Performance  
✅ Country-wise Sales  
✅ Time Series Analysis  
✅ Quarterly & Monthly Trends  
✅ Demographic Analysis  

The project demonstrates how Excel can be used as a complete Business Intelligence (BI) tool.

## 🔹 DAX Measures
Examples:
DAX
Total Revenue = SUM(FactInternetSales[Total Revenue])

Total Profit = 
SUM(FactInternetSales[Total Revenue]) - 
SUM(FactInternetSales[COGS])

Profit Margin = 
DIVIDE([Total Profit], [Total Revenue])

📊 Data Model Architecture

The project uses a relational data model with:

- FactInternetSales
- DimCustomer
- DimProduct
- DimDate
- DimGeography
- DimSalesTerritory

Relationships were built using Power Pivot to enable scalable and efficient analytics.
